청소를 한 번에 기록하고, 공간 색으로 관리 상태를 확인하는 1인 가구용 청소 기록 서비스입니다.

문제
기록이 번거로워 포기하고, 언제 청소했는지 헷갈려 같은 곳을 또 청소합니다.
컨셉
“한 칸만 칠해도, 오늘 청소는 성공”

기획 포인트

  • 홈 상태 4단계(설정 전, 기록 중, 관리됨, 관리 필요): 평가 대신 지금 상태를 공간 색으로 보여 줍니다.
  • 카드를 한 번 눌러 기록하고, 최근 기록·자주·공간별로 빠르게 찾을 수 있습니다.
  • 공간 사진으로 AI가 관리 항목을 추천하고, 사용자가 최대 10개를 확정합니다. 공간 2개 이상, 공간당 사진 1~3장일 때만 분석하며 완료·취소 시 사진을 삭제합니다.
  • 인식에 실패해도 사진은 유지한 채 다시 시도하거나, 사진 없이 기본 항목으로 시작할 수 있습니다.

두잇킷

중소 이벤트 대행사가 브랜디드 게임 캠페인의 제작부터 성과 보고까지 한곳에서 끝내는 AI SaaS입니다.

문제
제작·검토·운영·보고가 외주, 메신저, 시트로 흩어져 수정 전달과 결과 재정리가 반복됩니다.
컨셉
“게임 행사, 이제 외주 없이 대행사 이름으로”

기획 포인트

  • 제작→검토→게시→운영→성과를 하나의 흐름으로: 시안·설정은 검토 링크로, 확정 기록은 게시 근거로, 운영 데이터는 성과 보고로 이어집니다. 브랜드사별 워크스페이스로 행사·담당자·데이터를 분리했습니다.
  • 설정 옆에 고객 화면 미리보기를 두어 입력 결과를 바로 확인합니다. 대행사 브랜드는 시안·리포트·PDF·초대 메일에(두잇킷 표기 제외), 브랜드사 로고·색상은 참여자 화면에 적용합니다.
  • 제작·운영·성과에 AX를 더했습니다. AI는 보유 템플릿 TOP 3 추천, 참여 퍼널 병목 분석, 리포트 초안 작성까지 맡고, 적용·현장 조치·외부 공유는 담당자가 확인한 뒤 진행합니다.
  • 알림톡이 실패하면 문자로 대체해 개별·일괄 재발송하고, 초과 사용은 참여를 막지 않고 월 단위로 사후 정산합니다. AI 초안은 적용 전 상태로 되돌릴 수 있습니다.

삼국지로 배우는 데이터 분석

적벽대전의 기록을 직접 세고 숫자로 풀어 보며 데이터 분석의 순서를 익히는 학습 웹앱입니다.

문제
데이터 분석 입문자는 용어와 수식에서 막히고, 게임 능력치는 근거를 알 수 없습니다.
컨셉
“만약 그때, 다른 일이 있었다면?”

기획 포인트

  • 왜 적벽대전인가: 많은 사람이 알고, 인물·전투·계책이 기록으로 남아 직접 세어 볼 수 있는 이야기입니다(『삼국지연의』 제43~50회).
  • 인물과 배·불·계책 글자를 직접 세어 숫자로 바꾸고, 숫자가 나온 원문을 바로 확인하며 숫자가 곧 능력은 아니라는 한계도 스스로 찾습니다.
  • 질문 하나를 6단계로 풀며 분석 개념을 익힙니다. 각 단계는 사례 → 해 보기 → 결과 → 이름 순이라 용어가 먼저 나오지 않습니다.
    1. 명단 정하기
    2. 평균의 함정
    3. 지표 만들기
    4. 민감도 확인
    5. 근거 확인
    6. 가정 실험
  • 가정 실험: 제갈량을 조조 편으로 옮기면 지수가 83에서 72로, 바람도 따라간다고 두면 52(비슷함)가 됩니다. 분석이 정답 찾기가 아니라 근거로 비교하는 일임을 경험합니다.
